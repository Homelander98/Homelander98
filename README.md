## 🧭 Development Philosophy

> My workflow is guided by clarity, performance, and elegance. I don’t just write code—I architect experiences.

🎯 **User-First**  
Intuitive UI and smooth UX is non-negotiable. My apps feel native, fast, and frictionless.

🧼 **Clean Code**  
Architecture matters — I follow layered patterns, SOLID principles, and modular design.

📦 **Reusable & Scalable**  
Every component, screen, and service is built to scale and adapt — not just work.

🔐 **Secure by Design**  
Auth, roles, validations, rate limiting — security baked into every feature.

⚡ **Performance-Driven**  
Lazy-loading, cache control, memory optimization — your app shouldn’t just work, it should fly.

🛠️ **Tool-Oriented**  
I leverage the right tools to ship faster and smarter: Copilot, Postman, Firebase Console, Git Workflows.

🌐 **API-First Thinking**  
I treat APIs as core building blocks, not afterthoughts. Clean contracts, failovers, graceful fallbacks.

> 💡 *“Code is art, design is intent. I ship products that feel both.”*
